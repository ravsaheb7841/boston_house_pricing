About This Project

This House Price Prediction Web App is created using the Boston Housing Dataset. It predicts house prices based on 13 important features.

  • Crime rate
  • Number of rooms
  • Pollution level
  • Distance to key areas
  • Tax rate
  • Student–teacher ratio & more

Technologies used:

  • Python, Flask
  • Scikit-learn
  • Machine Learning (Regression Models)
  • Bootstrap UI

The model predicts prices in Lakh (₹) with proper Indian formatting. This project demonstrates real-world ML deployment.
